TimeTracker: UI mocks

Four screens from the design doc: the tray flyout and menu, the dashboard, naming an app, and settings (including autostart). The usage numbers are made-up sample data. The device name (DESKTOP-DEMO) is the real Windows computer name, which the app reads at every start. Hover over the charts and heatmap to see the tooltips the real UI will have.

Both modes are designed; the default follows Windows.

Mock 1: Tray icon, flyout and right-click menu

The only thing visible all day is the small icon in the notification area. A left-click opens the flyout with today at a glance. A right-click opens the menu (shown beside it for the mock; in reality only one is open at a time).

  • Hover tooltip on the icon: TimeTracker · Active today 3h 12m. A paused tracker gets a small badge on the icon.
  • The bar shows the day in three states. Locked or off time is not counted. Idle time is shown but not counted as active.
  • Apps whose file has no usable product name show up as their raw exe name. The flyout points them out so you can give them a proper name (Mock 3).
  • Settings… in the menu opens the settings screen (Mock 4), where autostart is switched on or off.
  • "Most used" is time in the foreground only. The dashboard also shows how long each app was open.

  • Every row shows the exe file under the name, and has a pencil to rename it. Apps with no detected name are flagged with Name this app. Renaming applies to all past data and to reports.
  • Period switch (Day / Week / Month / Year) and the arrows change every card at once. Day replaces the columns with a full timeline of the day.
  • The sum of the "In front" values equals the active time, since only one app is in front at a time. "Open" can be larger, which is why Discord and Spotify look long.

  • The name is a display label stored on the device, separate from the recorded data, so it applies retroactively and can be changed or removed at any time.
  • The raw exe name and path always stay visible as the secondary line, so you can tell what an entry really is.
  • A name can be shared: giving two exes the same name (or using "Merge into") combines their time in charts and reports.

  • Autostart on is the default after install. Switching it off removes the startup entry; the app keeps running until the next sign-in or Exit. Switching it on adds the entry again and needs no admin rights.
  • If someone disables TimeTracker in Windows Settings → Apps → Startup, the next manual start notices this and shows the status as "Blocked by Windows" with a link to that page.
  • With the PIN on, the autostart switch, Pause, Exit and Delete all data ask for it.
